# Конфигурация Tmux

Эта конфигурация Tmux оптимизирует работу за счёт полезных сочетаний клавиш, поддержки True Color, работы с мышью и буфером обмена, а также различных плагинов.  
Скрипт-пример `sample_run.sh` автоматически настраивает и запускает сессию с несколькими окнами.

![Скриншот](assets/screenshot.png)

## 📥 Установка

### 1. Установите Tmux
Если Tmux ещё не установлен:
```sh
sudo apt install tmux   # Debian/Ubuntu
brew install tmux       # macOS
```
Дополнительную информацию можно найти в [**Tmux Wiki**](https://github.com/tmux/tmux/wiki).

### 2. Установите переменную TERM
Добавьте в файл `~/.bashrc`:
```sh
export TERM=xterm-256color
```

### 3. Клонируйте репозиторий и примените конфигурацию
```sh
git clone --depth 1 https://github.com/vhstack/tmuxpp.git ~/.tmux
rm -rf ~/.tmux/.git ~/.tmux/assets ~/.tmux/README*.md
ln -s ~/.tmux/tmux.conf ~/.tmux.conf
```
Файл `clipboard.sh` должен остаться на месте — он нужен для работы с буфером обмена (см. ниже).

### 4. Установите TPM (Tmux Plugin Manager)
```sh
git clone --depth 1 https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
rm -rf ~/.tmux/plugins/tpm/.git
```
Подробнее см. в [**TPM-Repository**](https://github.com/tmux-plugins/tpm).

### 5. Установите плагины
Запустите Tmux и нажмите:
```
Prefix + I  # Устанавливает плагины
```

## ⌨️ Сочетания клавиш

- **Клавиша Prefix**: `Ctrl + A` (вместо `Ctrl + B`)
- **Окна и панели:**
  - `Prefix + +` → Создать новую сессию
  - `Prefix + c` → Создать окно
  - `Prefix + ,` → Переименовать окно
  - `Prefix + $` → Переименовать сессию
  - `Prefix + |` → Разделить по вертикали (панели рядом)
  - `Prefix + -` → Разделить по горизонтали (панели друг под другом)
  - `Prefix + b` → Вынести панель в отдельное окно
  - `Prefix + x` → Закрыть панель
  - `Prefix + &` → Закрыть окно
  - `Prefix + s` → Дерево сессий, отсортированное по имени
- **Навигация:**
  - `Prefix + ←, →, ↑, ↓` → Переключаться между панелями
  - `Alt + →` / `Alt + ←` → Переключаться между окнами
  - `Ctrl + Alt + →` / `Ctrl + Alt + ←` → Перемещать окно
- **Изменение размера панелей:**
  - `Prefix + j/k/h/l` → Изменить размер панели (с повтором)
  - `Prefix + z` → Развернуть/восстановить панель
- **Мышь:**
  - Колесо → Прокрутка буфера истории (3 строки за щелчок; режим копирования включается автоматически и выключается внизу)
  - Перетаскивание → Выделение, при отпускании кнопки текст копируется в буфер обмена
  - Двойной / тройной щелчок → Скопировать слово / строку
  - Правый щелчок → Вставить из буфера обмена
  - `Prefix + m` → Включить/выключить поддержку мыши
  - `Prefix + >` или `Alt + правый щелчок` → Контекстное меню панели
- **Режим копирования (клавиши vi):**
  - `Ctrl + PageUp` или `Prefix + [` → Войти в режим копирования
  - `v` → Начать выделение, `y` → Скопировать, `q` → Выйти
  - `Prefix + ]` → Вставить из буфера tmux
  - История: 50 000 строк на панель
- **Перезагрузить конфигурацию:**
  - `Prefix + r`

## 📋 Буфер обмена

`clipboard.sh` связывает tmux с буфером обмена системы. Файл должен лежать рядом с `tmux.conf` (путь определяется при загрузке конфигурации, по умолчанию `~/.tmux/clipboard.sh`). Подходящая утилита определяется автоматически:

| Платформа | Утилита | Установка |
| --- | --- | --- |
| WSL / Windows | `clip.exe`, `powershell.exe` (по желанию `win32yank.exe`) | уже есть в системе |
| macOS | `pbcopy` / `pbpaste` | уже есть в системе |
| Linux (Wayland) | `wl-copy` / `wl-paste` | `sudo apt install wl-clipboard` |
| Linux (X11) | `xclip` или `xsel` | `sudo apt install xclip` |

При копировании текст дополнительно отправляется в терминал, за которым вы сидите, через OSC 52. Этому пути не нужны утилиты на машине, поэтому он работает и на сервере без X/Wayland, и через SSH — если терминал поддерживает OSC 52 (Windows Terminal, WezTerm, kitty, iTerm2, Alacritty).
При вставке так не получится: из соображений безопасности OSC 52 разрешает только запись, но не чтение. Без локальной утилиты правый щелчок вставляет собственный буфер tmux — то есть именно то, что было выделено в tmux последним. `Prefix + ]` делает то же самое.
Чтобы использовать собственное выделение терминала, например через несколько панелей, удерживайте `Shift` при перетаскивании или отключите мышь через `Prefix + m`.

Управляются через TPM:
- `christoomey/vim-tmux-navigator` → Навигация, как в Vim
- `tmux-plugins/tmux-sessionist` → Управление сессиями
